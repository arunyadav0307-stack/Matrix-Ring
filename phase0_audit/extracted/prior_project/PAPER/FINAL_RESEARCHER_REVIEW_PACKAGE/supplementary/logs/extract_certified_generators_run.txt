PART 3.  TASK C: SYSTEMATIC SEARCH OVER THE EXTENDED FAMILY LIST
==============================================================================
  Every family of the census with a component lattice small enough
  to enumerate.  For each code the cheap invariants (dim D = k, the
  Euclidean hull h_E, the entanglement c = k - h_E, the dimension
  K = N - k - h_E, self-orthogonality, dual-containment) are computed
  for EVERY code; the expensive distance computation is run on a
  deterministically selected subset:
      * all SO / DC codes up to 150 per family;
      * the 120 EA codes with the smallest dual (largest possible d);
      * the 120 EA codes with the smallest entanglement (Task A).
  Distances come in cheap exact stages (weight <= 2, complete
  enumeration up to 262144 codewords, weight <= 3) and, for at most 25
  survivors per family, a deep support search to weight 6 (N <= 16) / 4 (N >= 20).
  Every reported value is either EXACT or a PROVED lower bound.

PART 6.  TASK E: INDEPENDENT CERTIFICATION OF THE HEADLINE CODES
==============================================================================
  Each certified code is the EXACT code found by the search (the
  image basis is carried through, no re-selection by invariants).
  Three independent methods:
    M1  complete enumeration of the relevant classical difference
        set (exact and complete when q^dim <= 3*10^6);
    M2  increasing-weight support search over F_q^N (a different
        algorithm: for each support it solves a left-kernel problem);
    M3  exhaustive search of the AMBIENT quantum space F_q^{2N} in
        increasing symplectic weight, testing commutation with the
        whole group V and non-membership of V (+) V.
  Plus: the stabilizer group is F_p-abelian, and K, c recompute.
