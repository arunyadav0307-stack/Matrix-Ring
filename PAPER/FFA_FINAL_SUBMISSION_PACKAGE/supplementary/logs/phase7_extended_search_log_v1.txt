PART 1.  TASK B: THE GENERAL CRT DECOMPOSITION, AND ITS VALIDATION
==============================================================================
  Phase 2C's Components routine covers only three regimes of
  X^n - 1 over F_q:  (S) split semisimple with all n-th roots of
  unity already in F_q, (C) n = p^v with t = 1, and (W) 'wild'
  n = p^v with t >= 2.  Everything else raised 'no component
  routine', which is why n = 5, 6 at t = 1 and n = 3 at q = 8 were
  unreachable (Phase 6, O-6.3).

  Replacement: factor X^n - 1 = prod g_j^{e_j} over F_q (trial
  division, verified by re-multiplication) and use the CRT
      B = A_t[X]/(X^n-1)  =  prod_j A_t[X]/(g_j^{e_j}),
  implemented as an F_q-linear ring isomorphism (matrix + inverse),
  so that B^2 = prod_j B_j^2 and every B-submodule of B^2 is a
  product of B_j-submodules of B_j^2.  The component lattices are
  tiny (dim B_j = t*deg(g_j)*e_j), so the product is exact and fast.

  Every step is verified: (i) the factorisation re-multiplies to
  X^n - 1; (ii) Psi is multiplicative on all pairs of basis
  elements; (iii) Psi o Psi^{-1} = id on a basis; (iv) the resulting
  submodule list is compared, as a SET, with the Phase-3B exhaustive
  BFS on every family the old routine supported.

PART 4.  TASK A: ENTANGLEMENT-EFFICIENT HIGH-DISTANCE CODES (O-6.1)
==============================================================================
  O-6.1 asked for a family in this framework with d >= 4, bounded
  entanglement c, and K >= 2.  The obstruction is exact, so we state
  it first and then measure against it.

  (a) STRUCTURAL FACTS (all verified on the data below).
      k = dim D = 2 dim_{F_q} W  is ALWAYS EVEN (the Gray image of
      the Morita code I_W has dimension 2 dim W), and N = 4tn is
      divisible by 4.  Hence
          K - c = (N - k - h_E) - (k - h_E) = N - 2k = 0 mod 4,
      i.e.  K = c (mod 4)  for every code, and in particular K and c
      have the same parity.  For the stabilizer routes h_E = k, so
      c = 0 and K = N - 2k is divisible by 4.

      The traded quantity is
          c + K = N - 2 h_E,      |c - K| = |2k - N|,
      so c is small iff the Euclidean hull h_E is large, i.e. iff the
      code is nearly self-orthogonal; and c >= 2k - N is forced.
      (Phase 6 section 12 stated 'c + K = N - k'; that is wrong, see
      PART 7, ERRATUM E-7.1: the correct identity is c + K = N - 2h_E,
      which agrees with the Phase 6 numbers only when h_E = 0.)

PART 5.  TASK D: NON-PRINCIPAL HULLS (O-6.4) AND THEIR STRUCTURE
==============================================================================
  O-6.4 asked whether mu_B >= 3 hulls occur only at (q,t,n) = (4,2,2)
  or reappear at (4,2,4), (8,2,2), (9,2,3).  The first part of the
  answer is structural, and it is decisive:

  THEOREM.  Let B = A_t[X]/(X^n-1) and W <= B^2.
   (i) B = prod_j B_j with B_j = A_t[X]/(g_j^{e_j}) and
       B_j ~= F_{q^{d_j}}[u,w]/(u^t, w^{e_j});
   (ii) mu_B(W) = max_j mu_{B_j}(W_j);
   (iii) B_j is a chain ring  <=>  t = 1 or e_j = 1;
   (iv) over a finite chain ring every submodule of S^2 is free of
        rank <= 2, hence 2-generated;
   (v) hence  mu_B(W) >= 3  REQUIRES  t >= 2 and p | n
        (p | n <=> some e_j >= 2, since X^n - 1 = (X^{n'}-1)^{p^v}).
  WARNING.  The chain hypothesis in (iv) cannot be dropped: over a
  non-chain local ring (t >= 2 and p | n, e.g. F_q[u,w]/(u^2,w^2))

E1.  the statement, the proof, and what is verified

  Claim (COMPUTATIONALLY VERIFIED ONLY / PROVED for the linear part).
  Let p = 2 and t even, and let H_t be the transported Hankel form
  matrix (Phase 4, T-177: H_t is ALTERNATING).  Then for EVERY

  I_{4n} (x) T of the Phase-5 remark.  (In characteristic 2 a

E2.  the exact domain of validity (t ODD is different)
------------------------------------------------------
  PROVED.  Let p = 2 and t = 2m+1 be ODD.  The transported form is
  B(x,y) = sum_{i+j=t-1} x_i y_j = <x, rho y>, rho the reversal
  permutation.  Split the index set into the fixed point {m} and
  the m pairs {i, t-1-i}: on each pair the Gram matrix is
  [[0,1],[1,0]] (a hyperbolic plane), on the fixed point it is [1],
  and the summands are mutually orthogonal.  Hence
       H_t  ~  (hyperbolic plane)^{(+) m}  (+)  <1>.
  For one such plane (basis u,v with B(u,u)=B(v,v)=0, B(u,v)=1)
  together with z, B(z,z)=1, z orthogonal to u and v, the vectors
       a = z+u,   b = z+v,   c = z+u+v
  satisfy B(a,a)=B(b,b)=B(c,c)=1 and B(a,b)=B(a,c)=B(b,c)=0, so
  <u,v,z> is isometric to I_3; absorbing the planes one at a time
  gives H_t ~ I_t for EVERY odd t.  A congruence therefore EXISTS
  for odd t, and the obstruction of E1 concerns t EVEN only.
  (Consistency: for t even the decomposition is m hyperbolic planes
  with no central <1>, and B(x,x) = 0 identically on a hyperbolic
  plane, so no orthonormal basis exists -- exactly E1.)
  NOTE.  A naive 'diagonalise by the greedy pivot and rescale' is
  NOT sufficient: the restriction of B to e^{perp} can be
  alternating for one admissible pivot and non-alternating for
  another, so the construction below backtracks over pivots.
