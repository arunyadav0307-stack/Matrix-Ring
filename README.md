# Quantum Error-Correcting Codes from Galois Hulls of Cyclic Codes over Noncommutative Matrix Rings

Working title. Research project executed under the controlling document
`00_BLUEPRINT/Research_Blueprint.pdf`.

**Current status: Phase 0 complete pending the independent audit. Phase 1 has
NOT been started** (the blueprint forbids starting a later phase before the
current one is accepted).

## Repository layout
```
00_BLUEPRINT/            controlling document (PDF) + text extract
01_LITERATURE/           annotated bibliography, BibTeX, comparison matrix
02_PHASE_REPORTS/        one folder per phase  -> Phase_0/Phase_0_Report.md
03_THEOREMS/             theorem_register.md (all results, with status + audit column)
04_COMPUTATION/          exact-arithmetic library, feasibility experiments, logs
05_MANUSCRIPT/           (empty until Phase 8)
06_AUDIT/                audit requests for the independent referee (ChatGPT)
PROJECT_DECISION_LOG.md  dated decisions and their rationale
CHANGELOG.md             scope / notation / assumption changes + file tree
```

## Reading order for a newcomer (or for the auditor)
1. `02_PHASE_REPORTS/Phase_0/Phase_0_Report.md` — the Phase-0 deliverable.
2. `03_THEOREMS/theorem_register.md` — what is claimed, and how strongly.
3. `04_COMPUTATION/README.md` — how to reproduce, and what the experiments do
   and do *not* prove.
4. `06_AUDIT/Phase0_audit_request.md` — the prompt to hand to ChatGPT.

## Standing rules (blueprint)
* One phase at a time; no phase is complete until the independent audit says so.
* Nothing is invented: no fabricated references, DOIs, theorems or numbers.
* Every claim is tagged established / proposed / conjectural / computational /
  open.
