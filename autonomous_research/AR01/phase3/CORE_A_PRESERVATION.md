## 1. Elementary ideal bound

**Lemma. Every ideal I of B has μ_B(I)≤2.**

If I contains an element with nonzero constant term, that element is a unit: for a=c+j, c∈k× and j∈J, the finite geometric inverse terminates because J³=0. Hence I=B and μ(I)=1.

Otherwise I⊂J. If I⊂J²=k·uw, it is either 0 or J², so μ(I)≤1. In the remaining case take f=a u+b w+c uw∈I with (a,b)≠(0,0). Then uf=b uw and wf=a uw show J²⊂I and JI=J². Thus

μ_B(I)=dim_k(I/JI)=dim_k(I/J²)≤dim_k(J/J²)=2.

This uses the nilpotent top-quotient argument in the foundations, not a claim that every B-submodule is free or that all B² submodules are two-generated. ∎

## 2. Preservation theorem

**Statement.** If W≤B² and μ_B(W)≤2, then **μ_B(H_s(W))≤2 for every s**. Equivalently every principal cyclic right ideal in the exact Core A matrix ring has a principal s-Galois hull, for all fields/twists in the stated range.

### Proof — two exhaustive cases

**Case A: W is not contained in JB².** Then W contains a primitive vector v=(a,b), meaning at least one entry is a unit. If a is a unit, the single equation

σ(a)z₁+σ(b)z₂=0

identifies D_s(Bv) with the free B-line generated by (−σ(a)^(−1)σ(b),1). If instead only b is a unit, solve for z₂; no ambient change of W or pairing is needed. Since H_s(W)⊂D_s(Bv), the hull is a submodule of a free B-line. Under its explicit B-linear isomorphism to B, H_s(W) corresponds to an ideal I≤B. The lemma gives μ_B(H_s(W))=μ_B(I)≤2.

**Case B: W⊂JB².** Coefficient Frobenius preserves J. Since JW⊂J²B² and J³=0, for v∈W and z∈JW we have β_s(v,z)=0. Hence

JW⊂H_s(W)⊂W.

Write d=dim_k(W/JW)=μ_B(W)≤2 and h=dim_k(H_s(W)/JW). Thus 0≤h≤d. If h=d, then H_s(W)=W, so its generator number is at most 2. If h=0, then H_s(W)=JW⊂Soc(B²), whose dimension is 2; a module killed by J needs exactly its k-dimension in generators, so again the bound follows.

The only remaining case is d=2 and h=1. Choose x∈H_s(W) whose coset spans H_s(W)/JW. Then

H_s(W)=k x+JW,       dim_k H_s(W)=1+dim_k JW≤3.

If x∈Soc(B²), all of H_s(W) lies in Soc(B²), so μ(H_s(W))≤2. If x is not in the ambient socle, Jx≠0. Since H_s(W) is a B-module, Jx⊂JH_s(W) and dim_k JH_s(W)≥1. Therefore

μ_B(H_s(W))=dim_k H_s(W)−dim_k JH_s(W)≤3−1=2.

These cases include W=0. They use neither σ²=id nor a classification of all embedded modules. The column packing dictionary now gives principality of the global hull. ∎
