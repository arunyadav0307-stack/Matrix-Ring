## Verify without running research

```sh
python3 -B NEW_RESEARCH_BLUEPRINT/scripts/verify_blueprint_archive.py /path/to/NEW_RESEARCH_BLUEPRINT.zip
```

It checks safe unique paths, CRC, exact file/manifest coverage, SHA-256 values, the ten names,79 context-copy identities, source/baseline indices,43 audit-family and18-topic/18-decision coverage, advisory-score arithmetic and the **new** documents' local links. If a sibling `.zip.sha256` is present, it checks the external archive digest too.
