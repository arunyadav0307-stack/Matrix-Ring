## 0. Conventions and the quantum framework (imported, with one clarification)

Throughout, `q = p^r`, `A_t = F_q[u]/<u^t>`, `R = M_2(A_t)`, `N = 4tn`, and
`D = phi_n(C) ⊆ F_q^N` is the Gray image of a right `R_n`-submodule `C`
(Phase 4, T-198).  All dimensions are over `F_q`; the quantum alphabet is
`F_q` (no `p`-ary substitution).

For an `F_q`-linear code `D ⊆ F_q^N` of dimension `k` with Euclidean dual
`D^{⊥_E}` and Euclidean hull `H_E = D ∩ D^{⊥_E}`, `h_E = dim H_E`, put

```
V  = D (+) D  =  {(a|b) : a, b ∈ D}  ⊆  F_q^{2N}
V^{⊥_ω} = D^{⊥_E} (+) D^{⊥_E},        rad V = V ∩ V^{⊥_ω} = H_E (+) H_E.
```

> **T-207 (PROVED).**  For every one of the three routes the quantum
> parameters of the code attached to `D` are
>
> | route | hypothesis | group | parameters |
> |---|---|---|---|
> | **R1** | `D ⊆ D^{⊥_hat_s}` (Galois) | the twisted graph `C_T = {(u|T_s u)}` | `[[N, N−k, d]]_q`, `d ≤ min wt(D^{⊥_E})` (T-194) |
> | **R2-SO** | `D ⊆ D^{⊥_E}` | `V` (isotropic) | `[[N, N−2k, d]]_q`, `d = min wt(D^{⊥_E}\D)` |
> | **R2-DC** | `D^{⊥_E} ⊆ D` | `V = D^{⊥_E}(+)D^{⊥_E}` (isotropic) | `[[N, 2k−N, d]]_q`, `d = min wt(D\D^{⊥_E})` |
> | **R3 (EA)** | none | `V` (not isotropic in general) | `[[N, N−k−h_E, d ; k−h_E]]_q` |
>
> and, writing `G` for the group in the third column of the table (`G = C_T`
> for R1 and `G = V` for R2/R3), in **every** case
>
> ```
> d = min{ swt(v) : v ∈ G^{⊥_ω} \ G },        swt(a|b) = #{i : (a_i,b_i) ≠ (0,0)}.
> ```
>
> (For R1 this is Phase 5's definition; the reduction to a *classical* minimum
> below is proved for R2/R3 only, and for R1 only the upper bound T-194 is
> available.)
>
> *Proof.*  `G` is the group generated by the check operators.  For R1 the
> group is the twisted graph, which is abelian under the stated hypothesis
> (T-193).  For R2 the group is isotropic, `V ⊆ V^{⊥_ω}`, and the usual
> stabilizer argument gives the formula.  For R3 the entanglement makes the
> **whole** group `V` measurable: for `v = s + Σ(α_i e_i + β_i f_i)` with
> `s ∈ rad V`, the part `s` stabilizes the codespace outright and each
> hyperbolic pair `e_i, f_i` is measured with the help of one ebit, on which
> the maximally entangled state satisfies `(A ⊗ I)|Φ⟩ = (I ⊗ A^T)|Φ⟩`; hence
> `v ⊗ I` fixes the codespace.  Consequently an error is *undetected* only if
> it commutes with all of `V` and lies outside `V`, i.e. exactly if it lies in
> `V^{⊥_ω} \ V`.  The parameters are `2c = dim V − dim rad V = 2(k−h_E)` and
> `K = N − dim V + c = N − k − h_E = N − dim rad V − c`.  ∎

Two consequences used throughout, both elementary:

1. **The minimum is a classical one.**  Since
   `swt(a|b) ≥ max(wt(a), wt(b))` and `(a|0) ∈ V^{⊥_ω}\V` whenever
   `a ∈ D^{⊥_E}\D`, the symplectic minimum equals
   `min{wt(x) : x ∈ D^{⊥_E} \ D}` (R2-SO, R3) resp.
   `min{wt(x) : x ∈ D \ D^{⊥_E}}` (R2-DC).
2. **Phase 5's T-197 is the same number, not a weaker one.**  T-197 states
   `d = min wt(D^{⊥_E}\Hull_E)`.  For `x ∈ D^{⊥_E}` one has
   `x ∈ D ⟺ x ∈ D ∩ D^{⊥_E} = H_E`, so
   `D^{⊥_E}\D = D^{⊥_E}\H_E` as sets.  The binding limitation in Phase 5 was
   therefore the *maximum search weight*, never the exclusion set.

**Notation for the certification (§3).**  `S` denotes the **physical**
stabilizer group: `S = G` for R1/R2 (the whole group is abelian there) and
`S = rad V = H_E (+) H_E` for R3.  The
general parameter identity used in §7 is

```
K = N − dim_{F_q} S − c = N − dim_{F_q} V + c,      2c = dim V − dim rad V.
```

Commutation is always tested on an `F_p`-basis of `S` with the trace-symplectic
form `Tr_{F_q/F_p}(a·b' − a'·b)` (T-203: an `F_q`-generator test is invalid
because `Tr_{F_4/F_2}(1) = 0`).

* **A2** — R2 and R3 do escape the cap: measured in this phase,
  `R1: d ≤ 2` everywhere (the cap is *attained*), `R2: d = 3`

  `[[12,2,6;10]]_4`).
* **A3** — the framework can only enumerate the families of §2; the longest

  `N = 24` (a **seeded sample** at `(4,2,3)`).  Longer `n` (`n = 5, 6` at
  `t = 1`, and `n = 3` at `q = 8`) are **not** supported by the current ring

  This is a computational boundary, recorded as such, not a structural one.

**Answer to O-5.2** (`is d_{R1} = min wt(D^{⊥_E}) exactly?`): yes in the
scanned range, and the mechanism is now exhibited (A1).  At `(4,2,2)`, `N = 16`

**Answer to the "inherent?" question.**  The limitation is **not** inherent in

pipeline produces `d = 5` and `d = 6` as soon as entanglement is allowed
(route R3).  It is (i) structural for R1 (T-194, proved), and (ii) a
consequence of the classical quality of the image codes for R2.

### 2.2 The distance is computed exactly, not bounded by a search weight

For every candidate the quantity `min wt(G \ E)` (`G` = the relevant classical
code, `E` = the excluded subcode) is computed in three passes, and the pass
that decided each value is printed in the log:

1. **pass 1** — increasing-weight support search up to weight 2 (cheap; exact
   if it finds a codeword, otherwise it *proves* `d > 2`);
2. **pass 2** — **complete enumeration** of `G` (every codeword) when
   `q^{dim G} ≤ 2·10^6`: exact and complete.  For `q = 2^r` this uses a
   reflected mod-`q` Gray code over the coefficients of an rref basis, so that
   consecutive codewords differ by one basis vector and both the codeword and
   its syndrome with respect to a parity-check matrix of `E` are updated by a
   single big-integer XOR (addition in `F_{2^r}` is bitwise XOR in the stored
   digit basis).  Membership in `E` is the single test `syndrome == 0`.  This
   enumerator was cross-checked against brute force on **110 instances with 0
   disagreements** (§13).
3. **pass 3** — otherwise a support search up to weight 6 (`N ≤ 16`) or 4
   (`N = 24`): exact if it finds a codeword, otherwise the proved lower bound
   `d > 6` resp. `d > 4`, reported as such.

## 3. Task C — exact quantum distance certification

strongest code of each family.  **No code is re-selected by invariants** — the
search stores the image basis of every reported code, so the certified code is
literally the code that produced the reported parameters.  Three methods are
run on each:

* **M1** — complete enumeration of the classical quotient (every codeword of
  `G` outside `E`); exact and complete whenever `q^{dim G} ≤ 2·10^6`.

  lower bound `d > w`.

## 5. Task E — the characteristic-two obstruction: exact domain and bypasses

### 5.1 The obstruction is not an artefact of one coordinate transformation

> **T-210 (PROVED, `[SMP]` corroborated).**  Let `p = 2` and `t` be even.  Then
> `H_t` is alternating (T-177), and for **every** invertible `F_q`-matrix `S`
> the matrix `S^T H_t S` is again alternating, since
> `(Sx)^T H_t (Sx) = 0` for all `x`.  As `I_t` is not alternating
> (`e_i^T I_t e_i = 1`), **no** congruence `S^T H_t S = I_t` exists.  The
> obstruction therefore applies to every *linear* physical-coordinate
> transformation, not merely to the block form `I_{4n} ⊗ T` used in Phase 5.
>
> (In characteristic 2 a symmetric `M` is alternating iff it has zero diagonal,
> because `x^T M x = Σ_i M_ii x_i^2` and `x ↦ x^2` is a bijection of `F_q`.)

Verified for `(q,t) = (4,2), (4,4), (8,2), (8,4), (4,6)`: `H_t` alternating
`True`; `S^T H_t S` alternating for **200 random invertible `S`** at each
parameter pair; `I_t` alternating `False`.  (`[SMP]` — the *proof* is
universal; the sample only confirms the implementation.)

### 5.2 The domain is exactly "t even"

> **T-211 (PROVED, constructively verified).**  Let `p = 2` and `t = 2m+1` be
> **odd**.  Then `H_t` is congruent to `I_t`.
>
> *Proof.*  `B(x,y) = Σ_{i+j=t−1} x_i y_j = ⟨x, ρy⟩` with `ρ` the reversal
> permutation.  Split the index set into the fixed point `{m}` and the `m`
> pairs `{i, t−1−i}`: on each pair the Gram matrix is `[[0,1],[1,0]]` (a
> hyperbolic plane), on the fixed point it is `[1]`, and the summands are
> mutually orthogonal, so `H_t ≅ (hyperbolic plane)^{⊕ m} ⊕ ⟨1⟩`.  For one
> such plane (basis `u,v` with `B(u,u)=B(v,v)=0`, `B(u,v)=1`) and `z` with
> `B(z,z)=1`, `z ⊥ u,v`, the three vectors
> `a = z+u`, `b = z+v`, `c = z+u+v` satisfy `B(a,a)=B(b,b)=B(c,c)=1` and
> `B(a,b)=B(a,c)=B(b,c)=0`; hence `⟨u,v,z⟩ ≅ I_3`.  Absorbing the planes one
> at a time gives `H_t ≅ I_t`.  ∎

Constructively verified (explicit `S`, checked by direct multiplication) for
`(q,t) = (4,1), (4,3), (8,1), (8,3), (4,5)`; and the same routine correctly
returns "no congruence" for `(4,2), (8,2), (4,4)`.

*Warning recorded in the log (a methodological point).*  A greedy
"diagonalise by the first non-zero diagonal entry, then rescale" elimination
**fails** here: the restriction of `B` to `x^⊥` can be alternating for one
admissible pivot and non-alternating for another.  The implementation
backtracks over pivots; the failure of the greedy version was observed and is
the reason for the backtracking.

**Consistency with §5.1.**  For `t` even the decomposition is `m` hyperbolic
planes with no central `⟨1⟩`, and `B(x,x) = 0` identically on a hyperbolic
plane, so no orthonormal basis exists — which is exactly T-210.

### 5.3 The bypasses that do exist, and what they yield

| bypass | valid? | what it yields in this framework |
|---|---|---|
| **R1** (twisted graph `{(u|T_s u)}`) | for every `s`; the transported Gram form replaces `H_t` | at `(4,2,2)`, `s = 0`: 59 of the first 60 codes give an abelian twisted group; distances `1` and `2`, the cap `d ≤ min wt(D^{⊥_E})` attained |
| **R2** (accidental Euclidean SO/DC) | only for those image codes that happen to be Euclidean self-orthogonal / dual-containing | `d = 3` at `(4,1,4)`; `d ≤ 2` for every `t ≥ 2` family |
| **R3** (entanglement) | for **every** code, no isotropy needed | `d = 6` (`[[12,2,6;10]]_4`), `d = 5` (`[[16,4,5;8]]_4`, `[[24,4,5;12]]_4`) |
| **J-frame CSS** `C' = A × (JB)` | when `A ⊆ (JB)^{⊥_E}` | valid, but the best distance over 398 valid `(A,B)` pairs at `(4,2,2)` and `(4,1,4)` is `d = 2` |

**Scope statement (required).**  Nothing above says that good codes are
